# Frontend Requirements

本文定义 HMHT 课程版前端的范围、角色、验收标准和边界。前端面向课程演示和本地联调，消费现有 Spring Boot REST API，不引入 MQTT、硬件直连、InfluxDB、Python 服务或多运行模式。

## Goals

- 提供可演示的 Web 操作界面。
- 覆盖登录、注册、节点查看、传感器曲线、设备统计、告警、定时任务、个人资料、管理员管理和操作日志。
- 以固定模拟节点 `SIM_Node_01` 为主线组织页面，同时允许管理员创建额外演示节点。
- 保持接口联调清晰、状态可恢复、错误提示可理解。

## Functional Scope

| Module | Page / Capability | Status | Notes |
|--------|-------------------|--------|-------|
| Auth | 登录、注册、忘记密码 | Required | 调用 `/v1/auth/*`，保存业务 token |
| Dashboard | 控制台概览 | Required | 节点、健康状态、告警摘要、快捷入口 |
| Node | 节点详情 | Required | 节点状态、传感器元数据、设备元数据、阈值信息 |
| Sensor | 历史数据 | Required | `temperature`、`humidity`、`light`、`soilHumidity`；`24h`、`7d`、`30d` |
| Equipment | 设备模板、设备控制演示、设备统计 | Required | 课程版只做前端展示和统计，不下发真实控制命令 |
| Alert | 告警列表与处理 | Required | 支持全部、未处理、已处理筛选和分页 |
| Task | 定时任务管理 | Required | 列表、创建、编辑、删除、启停 |
| Profile | 个人资料与改密 | Required | 资料修改、密码修改、登出 |
| Admin | 节点、用户、授权管理 | Required for admin | 根据 `profile.role` 展示入口 |
| Logs | 操作日志 | Required for admin | 支持分页和类型筛选 |

## Out Of Scope

- 真实设备开关控制或命令下发。
- WebSocket、Server-Sent Events 或实时推送。
- 地图、大屏、摄像头、溯源、聊天、文件上传或头像上传。
- 复杂权限系统；前端只控制入口展示，后端仍是最终权限边界。
- 离线缓存或跨设备登录态同步。

## Acceptance Criteria

| Page | Criteria |
|------|----------|
| 登录页 | 正确提交手机号/密码；失败时展示业务错误；成功后进入控制台 |
| 注册页 | 可获取测试验证码并注册；注册成功后可返回登录 |
| 控制台 | 展示节点、健康状态、未处理告警和常用入口 |
| 节点详情 | 展示节点基本状态、传感器类型、设备类型和阈值 |
| 历史数据 | 切换指标和时间范围后重新加载曲线；展示最大、最小、平均值 |
| 设备统计 | 切换设备后展示统计摘要和趋势数据 |
| 告警列表 | 可筛选和分页；处理成功后刷新列表 |
| 任务管理 | 可创建、编辑、删除、启停任务；校验小时、分钟和重复日期 |
| 个人资料 | 可读取和更新资料；修改密码成功后有明确反馈 |
| 管理页面 | 管理员可维护节点、用户角色和节点授权 |
| 操作日志 | 管理员可查看日志列表并按类型筛选 |

## UX Direction

- 类型：课程演示后台，不做营销落地页。
- 布局：侧边栏 + 顶部状态区 + 主工作区。
- 信息密度：表格、图表和状态摘要保持紧凑，方便课堂演示扫描。
- 颜色：以绿色、青色和黄色告警色辅助表达，不让单一颜色支配整个界面。
- 页面状态：每个数据区都需要 `loading`、`empty`、`error`、`ready` 状态。

## Sync Rules

- 新增或修改后端接口时，同步 `README.md`、`docs/api-endpoints.md`、`docs/frontend-api-mapping.md` 和 `CHANGELOG.md`。
- 修改固定节点、传感器类型、设备类型或种子账号时，同步本文档和相关 API 文档。
- 纯前端页面、样式或脚本变化也需要记录到 `CHANGELOG.md`。
